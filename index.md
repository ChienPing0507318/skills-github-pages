# Step 1: Enable GitHub Pages
1. Make sure this repository is **Public**.
2. In this repository, click **Settings**, click **Pages** in the **Code and automation** section.
3. Ensure **Deploy from a branch** is selected from the **Source** drop-down menu, and then select `main` from the **Branch** drop-down menu.
4. Click the **Save** button.
5. Refresh website Page, and now can see the link to website.
